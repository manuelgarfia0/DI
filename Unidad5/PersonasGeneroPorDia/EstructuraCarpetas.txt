Flujo de dependencias:

ListadoPersonasView
    -> ListadoPersonasVM
        -> IPersonaUsecase
            -> PersonaUsecase
                -> IPersonaRepository
                    -> PersonaRepository
                    -> PersonaRepositoryVacio
                    -> PersonaRepositoryDoscientas

El contenedor de Inversify configura las implementaciones y permite
sustituir el repositorio para probar distintos escenarios.

Ejemplo de DTO:

src/data/dtos/PersonaDTO.ts

export interface PersonaDTO {
    dni: string;
    nombre: string;
    genero: string;
}

Conversion de DTO a entidad:

const persona = new Persona(dto.dni, dto.nombre, dto.genero);

Propiedades de la entidad Persona:

- dni: getter solamente; no se puede modificar despues de construir la entidad.
- nombre: getter y setter; se puede consultar y modificar.
- genero: getter y setter; se puede consultar y modificar.

El DTO no contiene logica de negocio. La logica permanece en Persona y
PersonaUsecase.
