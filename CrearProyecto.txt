1. Crear proyecto: 

npx create-expo-app --template

2. Eliminar archivos innecesarios

npm run reset-project

3. Instalar Invesify

npm install inversify reflect-metadata

4. Instalar dependencias

npm install --save-dev @babel/plugin-proposal-decorators
npm install --save-dev @types/reflect-metadata @babel/plugin-proposal-decorators
npm install --save-dev babel-plugin-transform-typescript-metadata
npm install --save-dev @types/inversify

3. Instalar ngrok si da fallos(casi siempre da fallos)

npx expo install @expo/ngrok

4. Ejecutar proyecto (W para ver el web)

npx expo start --tunnel
